Firmo – تثبيت كتطبيق ويب (يعمل بدون إنترنت)
============================================

المحتويات المطلوبة معاً في نفس المجلد:
  index.html
  manifest.webmanifest
  sw.js
  icons/   (كل ملفات الأيقونات)

مهم: التثبيت والعمل دون إنترنت لا يعملان من file://
يجب فتح التطبيق عبر HTTP/HTTPS.

--------------------------------------------
تشغيل محلي (أي نظام)
--------------------------------------------
من داخل مجلد artifacts:

  python3 -m http.server 8000

ثم افتح: http://localhost:8000

أو:

  npx --yes serve -p 8000

--------------------------------------------
استضافة مجانية (HTTPS)
--------------------------------------------
- Netlify Drop: اسحب المجلد على https://app.netlify.com/drop
- GitHub Pages: ارفع المجلد كمستودع وفعّل Pages
- Cloudflare Pages / Vercel: اربط المجلد

--------------------------------------------
التثبيت حسب النظام
--------------------------------------------
Windows / Linux / Mac (Chrome أو Edge أو Brave):
  1) افتح رابط التطبيق
  2) أيقونة التثبيت في شريط العنوان، أو القائمة ⋮ ← تثبيت Firmo
  3) يظهر في قائمة التطبيقات ويعمل بدون إنترنت

Mac (Safari):
  قائمة ملف ← إضافة إلى Dock

iPhone / iPad:
  مشاركة ← إضافة إلى الشاشة الرئيسية

Android (Chrome):
  القائمة ⋮ ← تثبيت التطبيق / إضافة إلى الشاشة الرئيسية

Firefox لسطح المكتب:
  لا يدعم التثبيت كتطبيق — استخدم Chrome أو Edge

--------------------------------------------
التحقق من العمل دون إنترنت
--------------------------------------------
1) افتح التطبيق مرة وهو متصل
2) أغلق التبويب
3) عطّل الإنترنت
4) افتح التطبيق المثبّت أو أعد فتح الرابط — يجب أن يعمل
